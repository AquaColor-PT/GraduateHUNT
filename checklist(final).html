GraduateInHunt Pre-Launch Checklist

Checklist

Authentication & Access
  • Recruiters can log in and log out correctly
  • Session persistence works
  • Pages redirect properly if unauthenticated
  • Admin pages restricted correctly
Recruiter Profile
  • Profile data loads correctly
  • Password updates work
  • Profile picture upload and preview works
  • Credits display correctly
Credits System
  • Posting a job decrements credits
  • Buttons disabled when credits = 0
  • Disabled buttons redirect to "Buy Credits" page
  • Buying credits updates balance correctly
Job Posting & Management
  • New jobs can be posted
  • Editing and deleting jobs works
  • Job descriptions toggle correctly
  • Jobs visible only to posting recruiter
Payments (Admin Panel)
  • Pending payments load correctly
  • Approve/reject buttons update status and credits
  • Only pending payments appear
  • Proof URLs display correctly
UI & Responsiveness
  • Layout works on desktop, tablet, mobile
  • Buttons, inputs, navigation function correctly
  • Visual styles render correctly
Error Handling
  • Network/server errors handled properly
  • Input validation works
  • File upload restrictions enforced
Links & Navigation
  • All links navigate correctly
  • Logout clears session
  • Unauthorized redirects work
Security & Policies
  • RLS rules restrict access correctly
  • No sensitive keys exposed
  • Users cannot modify others’ data
Final Checks
  • Multiple recruiter accounts tested
  • Multiple jobs posting/editing/deleting tested
  • Credits flow tested
  • Alerts and console errors handled
