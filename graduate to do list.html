Graduate Side To-Do List

1. Authentication

  • Graduate registration (name, email, password, phone, CV upload)
  • Graduate login
  • Password reset / forgot password
  • Session management (stay logged in until logout or expiration)

2. Profile Management

  • Edit profile details (name, phone, email)
  • Upload/update CV
  • Optional: Add cover letter template or personal description
  • Optional: Profile picture upload

3. Job Browsing

  • Display all available jobs
  • Filter/search by job title, company, location, type (internship/entry-level)
  • Sort by most recent or deadline
  • Job details page with description, requirements, and recruiter info

4. Job Applications

  • Apply to a job (upload CV and optional cover letter)
  • View list of jobs applied to
  • Show application status (pending, accepted, rejected)
  • Edit or withdraw an application before deadline (optional)

5. Messaging

  • View messages from recruiters
  • Send follow-up messages to recruiter
  • Notifications for new messages (optional)

6. Notifications

  • Notify graduate when recruiter replies or application status changes
  • Optional: Email notifications

7. Dashboard

  • Summary of total jobs applied, pending applications, messages
  • Quick links to apply for new jobs or view messages

8. UX & Security

  • Responsive design (mobile and desktop)
  • Input validation (email, phone, CV file type/size)
  • Protect pages so only logged-in graduates can access
  • Secure file uploads (CVs)
